# Language Policy

## Responses
- Write all Kiro responses in English.

## Project Artifacts
Write the following in English:
- Documentation, specifications, requirements, designs, and task lists
- README files
- Code comments
- Development logs

## User-Facing Applications
- Use English as the primary language for all user-facing applications, unless explicitly specified otherwise.

## Official Source Documents
- Preserve official source documents in their original language, including Japanese legal and policy documents. Do not overwrite or rewrite them.
- Provide English explanations or translations as separate content where needed, and label them clearly as non-official.

## Writing Style
- Use clear, professional English suitable for international technical reviewers.
